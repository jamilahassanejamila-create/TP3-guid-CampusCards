# TP3-guid-CampusCards
Présentation du projet
-CampusCards est une application mobile développee avec React Native et Expo et TypeScript dans le cadre du TP3 du module de développement mobile. Et L'objectif de ce projet est de créer une interface qui affiche une liste d'étudiants sous forme de cartes individuelles, avec leurs informations et leur statut selon leur note.
